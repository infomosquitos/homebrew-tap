# infomosquitos Homebrew tap

```sh
brew install --cask infomosquitos/tap/spacemosquito
brew install --cask infomosquitos/tap/ticketmosquito
```

| Cask | Project |
|------|---------|
| `spacemosquito` | [infomosquitos/spacemosquito](https://github.com/infomosquitos/spacemosquito) |
| `ticketmosquito` | [infomosquitos/ticketmosquito](https://github.com/infomosquitos/ticketmosquito) |

`Casks/spacemosquito.rb` is generated by the SpaceMosquito release workflow
(`scripts/render-homebrew-cask.sh`). `Casks/ticketmosquito.rb` is generated by the
TicketMosquito release workflow. Do not edit either by hand — changes are
overwritten on the next release.
